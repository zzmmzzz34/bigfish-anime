Local Anime Player · v0.8

把番剧、线路和弹幕
收进一个干净的地方

大肥鱼番剧是一个本地运行的动漫聚合播放器：AniList 负责新番与周表，Bangumi 补中文评分与简介， 你的片源负责播放，B站弹幕负责热闹。没有广告，没有账号，也不提供在线片库。

What it does

信息优先，源退到线路里

首页只负责「逛」，详情页负责「选」，播放页负责「看」。片源名、线路、画质只在需要时出现。

新

AniList 新番与周表

当季 30 部、周一至周日放送表、全球评分，不再被单一平台的番剧库限制。

中

中文标题 + Bangumi

用 bangumi-data 把日文标题映射成中文；详情页补 Bangumi 评分、排名和中文简介。

线

多源线路与健康检查

跨片源自动合并线路，探测可用性、延迟和真实成功率，自动选最稳的一条。

弹

B站弹幕

B站番剧详情进入播放器时自动加载弹幕，按集缓存，和本地弹幕合并显示。

缓

SQLite 本地缓存

Bangumi 元数据与集数落盘；反代域名被墙时，继续用上次缓存的评分和简介。

净

干净、无广告

没有会员、没有弹窗、没有追踪；数据留在自己的电脑里，收藏和历史也不上云。

Get started

在自己的电脑上跑

  • 安装 Node.js 24+ 与 pnpm；Windows 也可以直接用仓库里的 start.bat。
  • 克隆仓库：git clone https://github.com/zzmmzzz34/bigfish-anime.git
  • 安装依赖：pnpm install，然后 pnpm dev 或双击 start.bat。
  • 打开 http://127.0.0.1:8787，在「片源」里配置你自己的 MacCMS / Kazumi 接口。
REQUIREMENTS

Node.js 24+ · pnpm · Windows / macOS / Linux

播放内容来自你自行配置的第三方片源；本项目不存储、不转码、不分发视频文件。

这是一个本地、非商业的学习/测试项目，不提供在线播放服务，也不对外提供片库。 B站 / AniList / Bangumi / DanDanPlay 的数据与接口归各自平台所有。
